# Improved Storyline v1.0.6

Патч, добавляющий возможность установить модификацию через [ComMod](https://github.com/Zvetkov/ComMod).

Это патч на **ванильную** версию игры. Разработка мода под эту версию игры заморожена, исключение составляют только критические баги, вызывающие софтлок игры.

Весь новый контент добавляется **только** в версию мода для [Community Patch/Remaster](https://github.com/DeusExMachinaTeam/EM-CommunityPatch).
